# MagicDNS (CascadeDNS)

> Быстрый защищенный DNS-шлюз для прямого доступа к ChatGPT, Claude, Perplexity и нейросетям без VPN на всех устройствах: ПК, смартфонах (iOS, Android) и консолях (Xbox, PlayStation).

## 🚀 Особенности
- **Zero-Dependency**: автономный легковесный `index.html` (весь CSS и JS встроен, мгновенная загрузка на GitHub Pages).
- **Дизайн**: тёмная кибер-тема (`#090d16` / `#0f172a`), акценты `#10b981` и `#06b6d4`, глассморфизм.
- **Поддержка геймпадов**: доступность и оптимизация под управление в браузере Xbox Edge.
- **Интерактивный статус-чекер**: пошаговая симуляция диагностики подключения и задержки.
- **iOS Профиль**: автономный DoH профиль `profile.mobileconfig`.

## 📦 Быстрый старт на GitHub Pages
1. Включите **GitHub Pages** в настройках репозитория (`Settings → Pages`).
2. Выберите ветку `main` (или `master`) и корень `/ (root)`.
3. Сохраните — сайт будет доступен по ссылке `https://<ваш-логин>.github.io/<репозиторий>/`.
